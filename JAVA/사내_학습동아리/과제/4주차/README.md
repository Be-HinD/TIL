# [과제 명세서] 숫자 야구 게임

> **제출 기한** : 다음 모임 전까지 (5.18)
> 
> **안내 사항** : 김경훈 책임, 김무현 책임을 제외한 인원들은 자바 중/상급자로서 아래 **[상급자 추가 요구사항]**까지 함께 구현해주세요.

---

## 1. 과제 개요

컴퓨터가 무작위로 선택한 3자리 숫자를 맞추는 숫자 야구 게임을 Java 콘솔 프로그램으로 구현한다. 변수, 연산자, 반복문, 조건문만 사용하여 완성한다.

## 2. 게임 규칙

* 컴퓨터는 1~9 사이 서로 다른 숫자 3개를 자릿수에 맞게 선택한다. (0 제외)
* 사용자는 3자리 숫자를 입력하고, 컴퓨터는 아래 기준으로 결과를 알려준다.
* 숫자와 자리가 모두 일치하면 **스트라이크**
* 숫자는 있지만 자리가 다르면 **볼**
* 숫자가 전혀 없으면 **아웃**


* 3스트라이크 시 정답으로 게임 종료

### 입출력 예시

```text
컴퓨터가 숫자를 선택했습니다.
맞춰보세요!

숫자 입력: 123
1볼 1스트라이크

숫자 입력: 456
아웃

숫자 입력: 139
3스트라이크 정답입니다!

시도 횟수: 3회

```

---

## 3. 요구사항 명세

| ID | 구분 | 상세 요구사항 |
| --- | --- | --- |
| **REQ-01** | 필수 | 컴퓨터는 1~9 중 중복 없는 3개의 숫자를 Math.random()으로 생성한다. |
| **REQ-02** | 필수 | 사용자로부터 3자리 숫자를 Scanner로 입력받는다. |
| **REQ-03** | 필수 | 스트라이크/볼 개수를 정확히 계산하여 출력한다. |
| **REQ-04** | 필수 | 3스트라이크 시 시도 횟수를 출력하고 프로그램을 종료한다. |
| **REQ-05** | 필수 | 볼도 스트라이크도 없으면 "아웃"을 출력한다. |
| **REQ-06** | 권장 | 입력값이 3자리가 아닌 경우 재입력을 요청하는 안내 메시지를 출력한다. |
| **REQ-07** | 권장 | 게임 종료 후 "다시 하시겠습니까?(y/n)" 물어보고 y 입력 시 재시작한다. |
| **REQ-08** | 선택 | 입력한 숫자에 중복이 있는 경우 재입력을 요청한다. |

## 4. 제약 조건

* **배열 사용 금지** (int[], String[] 등 사용 불가 — 아직 미학습)
* 라이브러리는 java.util.Scanner와 Math.random()만 허용

## 5. 구현 힌트

* **숫자 분리** : 3자리 정수를 각 자리수로 분리하려면 나누기(/)와 나머지(%)를 활용하세요.
* 예) int h = num / 100; $\rightarrow$ 백의 자리


* **중복 없는 난수 생성** : while 루프와 조건문으로 세 숫자가 모두 다를 때까지 재생성하세요.
* **스트라이크/볼 판정** : 자리별로 비교하는 중첩 if 구조로 충분히 구현 가능합니다.

* **제외 범위** : 주석 (//, /* */)
* **기산 범위** : 메서드 선언 줄 제외, 여는 { 다음 줄부터 닫는 } 전 줄까지
