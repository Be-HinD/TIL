# 차량 정보 관리 프로그램

> **클래스와 객체 복습**

---

## 1. 과제 개요

4차시에서 학습한 클래스, 객체, 필드, 메서드 개념을 복습합니다.
차량 정보를 담는 클래스를 직접 작성하고, 객체를 생성하여 정보를 출력하는 프로그램을 완성하세요.

---

## 2. 학습 목표

- 클래스를 직접 작성하고 필드와 메서드의 역할을 이해한다.
- `new` 키워드로 객체를 생성하고 필드에 값을 할당한다.
- 메서드를 호출하여 객체의 정보를 출력한다.
- **(선택)** 조건문을 활용하여 특정 조건의 차량만 출력한다.
- **(심화)** 싱글톤 패턴을 적용하여 객체 생성을 한 곳에서 관리한다.

> 해당 내용은 교재 **Chapter 6 클래스**의 5번 목차에 관련 정보가 포함되어 있습니다.

---

## 3. 요구사항

### 3-1. `Car` 클래스 작성

아래 필드와 메서드를 가진 `Car` 클래스를 작성하세요.

| 필드명      | 타입      | 설명                          |
|------------|----------|-------------------------------|
| `model`    | `String`  | 차량 모델명 (예: 아반떼, 소나타) |
| `year`     | `int`     | 출시 연도 (예: 2023)            |
| `color`    | `String`  | 차량 색상 (예: 흰색, 검정)       |
| `isRelease`| `boolean` | 현재 출시 여부                  |

> 필드는 필요한 정보를 더 추가해도 됩니다. (예: 차종 코드, 품번 등)
> 실제 시스템(알레그로, PDM)에서 사용되는 데이터를 필드로 구성해보는 것도 좋습니다.

---

### 3-2. 메서드 요구사항

| 메서드명           | 설명                             |
|------------------|----------------------------------|
| `printInfo()`    | 차량의 모든 필드 정보를 콘솔에 출력 |
| `changeRelease()`| 차량의 출시 여부를 변경            |

**출력 예시**

```
[ 차량 정보 ]
모델명   : 아반떼
연도     : 2023
색상     : 흰색
출시여부 : true
```

---

### 3-3. `Main` 클래스 작성

`Main` 클래스의 `main()` 메서드 안에서 아래 순서대로 구현하세요.

1. `Car` 객체를 N개 생성하고 각 필드에 값을 할당
2. 각 객체의 `printInfo()`를 호출하여 정보 출력
3. 특정 차량의 출시 여부를 `changeRelease()`로 변경 후 정보 출력
4. **(선택)** `isRelease`가 `true`인 차량만 조건문으로 골라서 별도 출력

> `Main` 클래스명은 변경 가능합니다. 단, `main()` 메서드는 모든 프로그래밍 언어의 시작 진입점이므로 변경 불가합니다.

---

### 3-4. (심화) 싱글톤 패턴 적용

싱글톤 패턴을 적용한 `CarFactory` 클래스를 추가하고, 객체 생성은 해당 클래스에서만 진행합니다.

**구현 조건**

- `CarFactory`는 싱글톤으로 구현 (인스턴스가 오직 1개만 존재해야 함)
- `createCar(String model, int year, ...)` : `Car` 객체를 생성하여 반환
- `Main`에서 `new Car()`를 직접 쓰지 않고 `CarFactory`를 통해서만 `Car` 객체 생성
- **(선택)** `Car` 객체를 `new` 키워드로 생성하지 못하도록 변경하여 `CarFactory`를 단일 생성 진입점으로 만든다.
  - 힌트: `private` 생성자

**사용 예시**

```java
CarFactory carFactory = CarFactory.getInstance();
carFactory.createCar(/* 차량정보 */);
carFactory.printAll();
```

---

## 4. 주의사항

- 클래스 파일과 메인 파일을 **분리하여** 작성할 것
- 요구사항의 **(선택)** 항목은 진행하지 않아도 됩니다.
- **심화 과제 대상자**는 코드 리뷰 시 싱글톤 패턴에 대해 설명할 것 (어떤 패턴이며 왜 사용하는지)
- 막히는 부분은 스터디 팀즈에 질문하거나 다음 차시 전까지 메모해 둘 것
